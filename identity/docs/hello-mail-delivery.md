# Prospect invitation mail

Production invitation and self-service password-reset messages leave through the Microsoft 365 `hello@mirrorprogress.com` mailbox using Microsoft Graph. The identity service retains its durable, encrypted invitation outbox and retries failed invitation sends. Password-reset requests use the same scoped mailbox transport. AWS SES production access is no longer the external-recipient gate when `IDENTITY_MAIL_DELIVERY=graph`.

The Microsoft Entra application is `Mirror Progress Security Mail` (`4de476ef-b1df-4777-b45b-241ec6722627`) in tenant `cd1b4d15-ba3e-41b9-a0ec-f7a9ed1027f5`. Exchange application RBAC assigns only `Application Mail.Send` to the `Mirror Progress Security Mail - hello only` scope. On September 26, 2026, `Test-ServicePrincipalAuthorization` returned `InScope=True` for `hello@mirrorprogress.com` and `InScope=False` for `ronniemack@mirrorprogress.com`. The application has no tenant-wide Graph `Mail.Send` grant.

The client secret is stored in AWS Secrets Manager as `mirror-identity/production/graph-mail-client`, encrypted under the production foundation Secrets KMS key. The ECS execution role can retrieve only this secret; the application receives it as `IDENTITY_GRAPH_CLIENT_SECRET`. The secret was created September 26, 2026 and expires March 25, 2027. Rotate it before expiry by creating a new Entra credential, updating the AWS secret, redeploying the service to refresh its environment, verifying a test send, then removing the previous Entra credential. Never put its value in Git, logs, task environment plaintext, or chat.

Before enabling the Graph configuration, a test `POST /users/hello@mirrorprogress.com/sendMail` returned HTTP 202 to the hello mailbox. The CDK `graphMailClientSecretArn` setting enables Graph mail and removes the task role's SES permissions. The admin invitation form reports external delivery ready only after configuration is verified and a Graph access token can be acquired. If Graph rejects a send, the outbox records a retry; acceptance is not evidence that the recipient opened the message.

To diagnose delivery, inspect the identity ECS service and its CloudWatch log group, the invitation outbox, and the `hello@mirrorprogress.com` Sent Items. Do not use SES sandbox status as a proxy for Microsoft 365 delivery. Disable the Graph transport by reverting the service image/configuration together to a known-good version; removing only the secret while Graph mode remains enabled prevents the task from starting.
