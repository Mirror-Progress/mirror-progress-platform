# Prospect header and assistant UI

These `.txt` files are source snapshots from the current private Prospect release, saved here because the public repository's root `client` is an obsolete baseline. Remove the `.txt` suffix when copying them into the matching paths of `identity-release/client`; do not apply them to the root `client`.

The update gives the Ask logo a mineral-green light-mode color, refines the menu/account/theme controls, and adds layered glass and depth to the assistant card and composer. On phones, it condenses the summary and view switch, collapses search and filters, opens with the globe unobstructed, and keeps a single Ask control in the header. It was checked at 320px and 390px, including chat close and reopen. TypeScript and the Next.js production build pass locally.

No GitHub Actions deployment is required for this source record.

The Market Pulse source snapshots add a keyless, sourced economic ticker to Prospect. The data service refreshes World Bank development indicators and commodity indices plus IRENA renewable capacity, caches the last good result, and exposes only the latest available country figures. The ticker includes a searchable market picker with a mobile-friendly menu. The source snapshots include the matching product and local-preview API routes, agent market context, and the exact package manifest and lockfile from the release client. Copy these files into `identity-release/client` without the `.txt` suffix; the root `client` remains obsolete. The release client passed TypeScript and focused lint checks, and the picker was exercised at desktop and 390px mobile widths.

The city-anchor snapshot adds approximate California city and regional reference points for 32 projects that appeared at one U.S. country marker in the production globe. The coordinates come from the [2025 U.S. Census California places](https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2025_Gazetteer/2025_gaz_place_06.txt) and [counties](https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2025_Gazetteer/2025_gaz_counties_06.txt) gazetteers, with NASA's published Moffett Field reference for that project. The matching test snapshot checks that the 32 projects remain selectable and disperse across the map.

The light-mode mobile market control now uses legible light text and borders on its dark ticker surface, including its search menu. It was visually checked at 390px with the chat open.

The Prospect assistant now streams answer text in bounded chunks and continues automatically when Bedrock reports `max_tokens`, preserving one continuous chat answer until `end_turn`. Recent conversation text can retain up to 12,000 characters per turn. A local long-answer test produced roughly 68,000 characters across five continuations and ended with a completion event.

The globe marker style snapshot removes the global 250 ms `transform` transition from the numbered marker buttons. Their projected positions now update in the same animation frame as the globe; only color, border, shadow, and opacity retain short transitions. The local globe preview confirmed the computed marker style excludes `transform` before and after a drag.

The trial snapshots add a one-step Identity invitation form for enrolled Mirror Progress admins. GaMarry's active admin account has invitation authority; Jahlon's project-lead account gets a separate trial-only permission in migration 006, without access to general account invitations. The trial defaults to 14 days but accepts 1–365 days, starts on the invited owner's first successful Prospect sign-in, and has no read-only grace. At expiry the account can still sign in while the workspace is blocked behind an opaque blur and billing prompt. Apply identity migrations 005 and 006 before serving the new Identity form, and deploy the Prospect API before Identity so trial preparation is available when an admin sends an invite. No invitations are sent by this source update.

## Prospect guided walkthrough

The versioned active Prospect workflow provides a first-entry walkthrough and a Replay walkthrough control in the main menu and Account settings. It highlights the existing globe, filters, project detail tabs, evidence, and assistant with responsive motion. Scenes requiring unavailable capabilities are omitted, and an absent screen anchor is skipped. Completion and skip status are scoped to the authenticated account and workflow version. The local preview uses browser storage. The assistant can request a validated scene through its Bedrock tool, and the chat offers direct guide shortcuts. The source snapshot includes the client, server route, agent event contract, styles, and focused tests. The root `client/` remains an obsolete baseline; deploy from the private `identity-release/client` source tree.

The assistant now has a validated tool for ordered, interactive screen guides as well as individual screen highlights. Its chat suggests guide requests. Closing chat keeps the active answer running, while reopening restores the same conversation; signed-in conversations are saved per account in Prospect and can be reopened from Previous chats. The local preview saves history in the browser. The expanded chat column now collapses with the panel, and walkthrough transitions remove the hidden chat from layout while preserving its state. The snapshot includes the new authenticated chat-history API.

## Prospect Source workspace and navigation

The Source workspace now opens inside Prospect with a source list, readable original/English sections, citation and notebook controls, and the same account-backed assistant used in Discovery. Source questions provide the selected evidence to a read-only Bedrock tool after checking that the project belongs to the current Prospect account. The selected chat and its source context carry between views. Discovery source links and the return control use a short page transition, while the source route prepares project evidence during navigation so the reader does not appear after an empty screen. The Source view follows Prospect's saved light/dark preference, includes its own theme control, and preserves that setting on return. A connected local Discovery and Source sample is included for visual review. These snapshots are from the private release client, not the obsolete public root client.

Ticker items now open a normalized Prospect market-detail panel instead of navigating straight to raw provider JSON. The panel shows the observation period, geography, publisher, retrieval date, interpretation, and scope limitation. The original dataset remains available as a separate link. The interaction was visually checked on desktop and at 390px mobile width.
